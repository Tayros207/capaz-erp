# Evaluación del asistente por modelo · 2026-11-26

Banco: `apps/api/src/core/agente/evaluacion/` (bucle, instrucciones y herramientas reales; ejecución simulada; datos inventados).
Se corre con `pnpm --filter api exec vitest run -c vitest.eval.config.ts`. **Cuesta dinero**: solo con orden del dueño.

Nueve casos, **una repetición por modelo**: sirve para detectar fallos, no para dar porcentajes firmes.

## Qué se cambió
- `pedido_editar` quita o pone el IGV sin reenviar las líneas.
- Los argumentos mal formados (texto en vez de lista o sí/no, datos fuera de `args`) se reparan antes de la política.
- Al fallar, el modelo recibe lo que llegó y el esquema; al tercer fallo seguido la herramienta se frena.
- Crear y editar pedidos y crear clientes están a mano en cualquier pantalla.
- Un origen de documento inventado ya no se envía.
- Los campos vacíos de los resultados no viajan al modelo.
